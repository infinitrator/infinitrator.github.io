# Лабораторная работа №1

## Тема

Создание статического сайта на MkDocs и публикация через GitHub Pages.

## Цель

Разобраться с MkDocs, структурой статического сайта, Git и публикацией сайта через GitHub Pages.

## Задание

Нужно было:

1. Создать публичный репозиторий на GitHub.
2. Создать проект MkDocs.
3. Сделать несколько страниц и настроить меню.
4. Подключить тему оформления.
5. Собрать сайт в каталог `docs`.
6. Опубликовать его через GitHub Pages.

## Выполнение

Для проекта создан каталог `source`, в котором находятся исходные Markdown-файлы и конфигурация MkDocs.

Для локального запуска используется команда:

    mkdocs serve

Для сборки сайта используется:

    mkdocs build -d ../docs

В качестве темы используется Material for MkDocs.

Исходники страниц находятся в `source/docs`, а готовый сайт собирается в каталог `docs` в корне репозитория.

## Результат

Получился статический сайт с главной страницей, страницей обо мне и отдельным разделом для лабораторных работ.

Собранная версия публикуется через GitHub Pages.

## Вывод

Разобрался с базовой структурой MkDocs, настройкой `mkdocs.yml`, сборкой статического сайта и публикацией через GitHub Pages.
