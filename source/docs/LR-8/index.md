## Цель работы

Получить данные с новостного сайта ITMO.NEWS с помощью веб-скрапинга:
сначала собрать общий список публикаций, а затем извлечь содержимое каждой
отдельной новости.

Для работы использованы `requests`, `BeautifulSoup` и `pandas`.

## Сбор общего списка новостей

Парсер последовательно обходит страницы раздела `main_news`.

Для каждой публикации извлекаются:

- целочисленный идентификатор новости из URL;
- название;
- дата размещения;
- URL страницы новости.

В итоговом общем датасете собрано **1147 уникальных новостей**.

Пропущенных идентификаторов, названий, дат и URL в собранном списке нет.
Дубликаты идентификаторов отсутствуют.

Общий список сохранён в файле:

`lab8/news.csv`

## Сбор содержимого новостей

После формирования общего списка открывается страница каждой публикации.

Для каждой новости собираются:

- идентификатор;
- название;
- дата размещения;
- количество просмотров;
- текст;
- теги;
- URL.

Итоговые данные сохранены в:

`lab8/news_content/news_content.csv`

Всего успешно обработано **1147 из 1147** страниц.

Ошибок HTTP-запросов или необработанных страниц после финального запуска нет.

## Вариативность верстки

При выполнении работы обнаружилось, что разметка ITMO.NEWS менялась с течением
времени.

Для получения основного текста используются несколько вариантов контейнера
статьи. Текст извлекается из контейнера целиком, а не отдельным объединением
каждого тега `<p>`.

Это необходимо из-за старых материалов с вложенными HTML-абзацами. При
независимом чтении каждого `<p>` содержимое вложенных элементов могло несколько
раз попадать в итоговый текст и искусственно увеличивать его размер.

После исправления максимальная длина текста в датасете составляет около
29 тысяч символов вместо ошибочных значений более 200 тысяч символов.

## Старые публикации и просмотры

Для **187** старых публикаций поле количества просмотров отсутствует
непосредственно в HTML сайта.

В этих случаях `views` оставлено как пропущенное значение (`NaN`). Значение
не заменялось нулём, поскольку ноль означал бы известное количество просмотров
и искажал исходные данные.

## Интерактивные публикации

Одна из публикаций представляет собой интерактивный материал и не содержит
обычного текстового тела в серверном HTML.

Поэтому для неё поле `text` также сохранено как пропущенное значение, вместо
того чтобы записывать служебный текст интерфейса.

## Вывод

В работе реализован двухэтапный скрапинг ITMO.NEWS.

Сначала сформирован полный список новостей с идентификаторами, названиями,
датами и URL. Затем для каждой публикации получены подробные данные: просмотры,
основной текст и теги.

Парсер учитывает различия между новой и исторической версткой сайта,
не создаёт дубликаты и сохраняет отсутствующие на исходной странице данные
как пропущенные значения.
